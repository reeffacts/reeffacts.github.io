Reef Facts - Privacy Policy

Last updated: 2026-11-09

Reef Facts is a YouTube channel that publishes short animated videos about marine life. This policy describes the "Reef Facts Uploader", a private tool the channel owner uses with YouTube API Services to publish videos to, and read statistics for, the Reef Facts channel. It is not offered to the public and is used only with the channel owner's own Google account.

Information the tool accesses

  • The Reef Facts channel's own videos: uploading new videos, setting their title, description, tags, category and scheduled publishing time, and deleting videos the tool uploaded.
  • The Reef Facts channel's own analytics: aggregate statistics such as views, watch time and retention, used to decide which topics to make next.

The tool does not access other users' channels, private data of viewers, or any Google account other than the channel owner's. It does not use cookies and does not collect information from visitors of this page.

How information is used and stored

  • OAuth credentials are stored only as encrypted secrets in the channel's private GitHub repository and are used solely to call the YouTube Data API and YouTube Analytics API for the Reef Facts channel.
  • Video metadata and aggregate analytics are stored in that private repository to plan future videos.
  • No information is sold, rented or shared with third parties, and none is used for advertising.
  • Aggregate analytics are kept for as long as the channel is active and can be deleted at any time by the owner.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Information is handled in line with the Google Privacy Policy. Access granted to the tool can be revoked at any time on the Google security settings page.
